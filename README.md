# Tallinjeeventyret

Et norsk regnespill i nettleseren. Velg gutt eller jente og løs oppgaver med addisjon, subtraksjon, multiplikasjon og divisjon. Riktig svar flytter figuren til svaret på tallinja og gir high five fra en alv. Feil svar flytter figuren ti felt tilbake, mens en tegneserierøver tar en gullmynt og løper av gårde. Spillet viser løsningen. Nå 100 for å vinne.

## Kjør lokalt

Åpne `index.html` direkte i nettleseren, eller kjør fra prosjektmappen:

```sh
python3 -m http.server 8000
```

Åpne deretter localhost på port 8000 i nettleseren. Ingen pakker, byggetrinn, eksterne tjenester eller API-nøkler kreves.
